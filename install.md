# Установка scroll-hero на as-building.by

Пакет заменяет первый экран (слайдер с тремя фото) на скролл-сцену: орбита → падение → стройка → готовый дом. Остальная главная остаётся нетронутой: старый hero скрывается, все секции ниже работают как раньше.

Состав: `hero.css`, `hero.js`, четыре папки кадров (`frames`, `frames-m`, `frames-space`, `frames-space-m`), `snippet.html`.

## Важно перед началом

- Доступа к вашему серверу у меня нет. Ниже шаги, которые нужно выполнить в админке или по FTP. Если дадите SFTP или доступ в wp-admin с правом ставить плагины, сделаю сам.
- Вес кадров 31 МБ на диске, посетитель грузит их прогрессивно: сначала каждый 12-й кадр (страница живая сразу), остальные в фоне. На телефоне отдельный лёгкий набор.
- Скрытый старый слайдер останется в HTML с `display:none`. Это нужно, чтобы ничего не сломать в остальной вёрстке. Поисковики такой контент не индексируют, наш заголовок `h1` — в новом блоке.

## Шаг 1. Залить файлы

По FTP или через файловый менеджер хостинга создайте папку:

```
/wp-content/uploads/asb-hero/
```

и положите в неё содержимое папки `asb-hero` целиком, чтобы получилось:

```
/wp-content/uploads/asb-hero/hero.css
/wp-content/uploads/asb-hero/hero.js
/wp-content/uploads/asb-hero/frames/001.webp … 147.webp
/wp-content/uploads/asb-hero/frames-m/…
/wp-content/uploads/asb-hero/frames-space/001.webp … 142.webp
/wp-content/uploads/asb-hero/frames-space-m/…
```

## Шаг 2. Подключить блок

### Способ A — Elementor (быстро, без правки темы)

1. Открыть главную в Elementor.
2. Найти секцию со слайдером: `b20bacc`. Внимание: `bb65461` — это контейнер, внутри которого вся страница, его трогать нельзя.
3. Перетащить виджет **HTML** прямо перед этой секцией.
4. Вставить содержимое `snippet.html` целиком.
5. Опубликовать, очистить кэш (Elementor → Инструменты → Regenerate CSS, плюс кэш-плагин, если стоит).

Старую секцию со слайдером удалять не нужно: скрипт скрывает только `b20bacc`. Никогда не добавляйте в `oldHeroSelectors` id `bb65461` — это обёртка всей страницы, вместе с ней исчезнет весь контент.

### Способ B — дочерняя тема (надёжнее, грузится в шапке)

В `functions.php` дочерней темы:

```php
add_action('wp_enqueue_scripts', function () {
    if (!is_front_page()) return;
    $base = content_url('/uploads/asb-hero');
    wp_enqueue_style('asb-hero', $base . '/hero.css', [], '1.0');
    wp_enqueue_script('asb-hero', $base . '/hero.js', [], '1.0', true);
    wp_add_inline_script('asb-hero', 'window.ASB_HERO={framesBase:' . wp_json_encode($base . '/') . '};', 'before');
});
```

### Способ C — плагин сниппетов (WPCode, Code Snippets)

Тот же PHP-код из способа B вставить как сниппет с запуском на фронтенде.

## Шаг 3. Проверить

1. Главная открывается, первый экран — космос с вращающейся Землёй.
2. Скролл вниз: падение, затем стройка. Остановились — кадр замер. Прокрутили назад — дом разбирается.
3. Ниже hero секция «Поможем выбрать участок» и остальные блоки на месте, ничего не съехало.
4. В консоли браузера нет красных ошибок.

Если кадры не грузятся (чёрный экран, проценты не растут) — почти всегда неверный `framesBase`. Проверьте в браузере прямой адрес:
`https://as-building.by/wp-content/uploads/asb-hero/frames/001.webp`

## Настройки (необязательно)

Перед подключением `hero.js` можно задать:

```html
<script>
window.ASB_HERO = {
  framesBase: '/wp-content/uploads/asb-hero/',
  scrollVh: 900,        // длина скролла на десктопе: больше = медленнее
  scrollVhMobile: 760,  // то же для телефона
  split: 0.42,          // доля скролла на космос, остальное стройка
  blend: 0.022          // ширина наплыва на стыке
};
</script>
```

Если 12 экранов прокрутки кажутся долгими, поставьте `scrollVh: 600`. Меньше 450 ставить не стоит: кадры начнут проскакивать.

## Откат

Удалить HTML-виджет (или снять сниппет) — страница мгновенно вернётся к старому слайдеру, он никуда не удалён.

## Что стоит доработать на проде

1. Водяной знак Hailuo в космическом сегменте. В пакете он срезан кропом 5 % справа и снизу. Перегенерировать в Pro-режиме — знака не будет вовсе.
2. Космический переход заканчивается на поле, которое не совпадает с их участком. Для честной стыковки нужен финальный кадр именно их дома (или перегенерировать с end-frame).
3. Если нужно, чтобы hero работал и на внутренних страницах, в сниппете уберите проверку `is_front_page()`.
